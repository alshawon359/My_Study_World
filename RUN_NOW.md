# 🚀 MY STUDY WORLD - এখনই চালান!

## তিনটি সহজ ধাপ:

### ১. Install করুন (একবার)
```bash
cd my-study-world
npm install
```

### ২. Database Setup করুন (একবার)
```bash
npm run db:push
npm run db:seed
```

### ৩. Run করুন
```bash
npm run dev
```

## ব্রাউজারে যান: http://localhost:3000
